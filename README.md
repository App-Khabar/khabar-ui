# KHABAR React Native Web

This project is a React Native + Expo conversion of the KHABAR mobile UI product.

## Screens
- Feed
- Search
- Categories
- Bookmarks
- Settings

## Run
1. Install deps:
   npm install
2. Start web app:
   npm run web

## Notes
- Top-right `Search` in the app bar opens the Search screen.
- Theme toggling is available in Settings (`Dark Mode`).
